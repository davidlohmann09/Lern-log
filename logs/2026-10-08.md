## Gelernt

### Benutzer verwalten
| Befehl | Zweck | Wichtige Optionen |
|---|---|---|
| `useradd` | anlegen | `-m` Home-Ordner anlegen, `-d` Home festlegen, `-s` Shell |
| `usermod` | ändern | `-d` Home ändern, `-m` Ordner mitverschieben, `-s` Shell |
| `userdel` | löschen | ohne Option: Ordner bleibt, `-r` Ordner mitlöschen |

- `useradd` ohne `-m` trägt den Benutzer nur ein, der Ordner wird **nicht** angelegt.
  → Eintrag anlegen ≠ Ordner anlegen. Immer mit `ls /home` prüfen.
- Optionen stehen zwischen Befehl und Benutzername, der Name kommt ans Ende.
- Optionen mit Wert gehören zusammen: `-d /home/gotham`. `-m` ist ein reiner Schalter.
- Gleicher Buchstabe, andere Bedeutung: `-m` bei `useradd` = Ordner anlegen, bei `usermod` = Ordner verschieben.

### /etc/passwd lesen
`batman:x:5002:5003::/home/gotham:/bin/sh`
→ Name : Passwort (steht in /etc/shadow) : User-ID : Gruppen-ID : Kommentar : Home : Shell
- Die IDs sind fortlaufende Nummern, die müssen nicht mit dem Beispiel übereinstimmen.

### System-Infos
- `whoami` = Wer bin ich? (der Fahrer)
- `uname` = Auf welchem System bin ich? (das Auto). `-r` Kernel-Version, `-a` alles
- Kernel = Motor des Betriebssystems, spricht direkt mit der Hardware.
- Alle Linux-Systeme haben denselben Kernel, drumherum unterscheiden sich die Distributionen
  (Ubuntu, Debian, Fedora, Kali …). Welche läuft: `cat /etc/os-release`

### Ausgabe umleiten
- Jeder Befehl kann seine Ausgabe in eine Datei schreiben, nicht nur `echo`.
- `>` = neu anfangen (Datei anlegen oder überschreiben)
- `>>` = weiterschreiben (Datei anlegen oder anhängen)
- `touch` braucht man dafür nicht.
- Bericht → `>`, weil der alte nicht mehr interessiert. Logbuch → `>>`, weil die Geschichte bleiben soll.

## Wo ich gehangen habe

- Bei `>` dreimal hintereinander → nur die letzte Zeile übrig, weil jedes Mal überschrieben wurde.
